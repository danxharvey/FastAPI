# Design Workflow Template

## Phase 0: Requirement Analysis
- Understand the design request and constraints.
- Review project architecture.

## Phase 1: Design Drafting
- Propose modular, plug-and-play solutions.
- Consider object-oriented patterns when they improve clarity or reuse.

## Phase 2: Review & Verification
- Check compatibility with existing modules.
- Document patterns and rationale for future reference.
