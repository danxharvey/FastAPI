# Test Workflow Template

## Phase 0: Analysis
- Identify modules and functions affected by the change.
- Determine critical edge cases and scenarios.

## Phase 1: Test Design
- Write unit tests first, covering normal and edge cases.
- Use modular test design so tests can be reused.

## Phase 2: Test Execution
- Run tests incrementally.
- Apply Safe Decision-Making: stop and ask user if tests fail on 3 consecutive runs.
- Update test coverage reports.
